Electronic spreadsheets allow users to organize, analyze, and visualize data efficiently. LibreOffice Calc, an open-source spreadsheet application, aligns with the CBSE Class X syllabus to teach core spreadsheet concepts such as formulas, functions, charts, conditional formatting, and data analysis.

## 1. Introduction to LibreOffice Calc
**Key Concepts:**
- Spreadsheet: Grid of rows and columns for data storage.
- Cell: Intersection of a row and column; identified by a cell address (e.g., A1).
- Workbook: Collection of worksheets.

**Practical Example:**
Enter sales data for a month in cells A1:B5.

**Shortcut Keys:**
- New Workbook: **Ctrl+N**
- Open Workbook: **Ctrl+O**

---

## 2. Workbook and Worksheet Management
**Key Concepts:**
- Adding, renaming, deleting worksheets.

**Steps (Flowchart):**
1. Open Calc → **Insert → Sheet**
2. Right-click sheet tab → **Rename**
3. Right-click sheet tab → **Delete**

**Shortcut Keys:**
- Insert Sheet: **Shift+F11**
- Rename Sheet: **F2**

---

## 3. Data Entry and Formatting
**Key Concepts:**
- Data types: Text, Number, Date.
- Formatting: Font style, cell color, borders.

**Steps:**
1. Select cell(s)
2. **Format → Cells**
3. Choose category (Number, Font, Border)

**Common Mistake:**
Entering numeric data as text (leading apostrophe).

**Shortcut Keys:**
- Bold: **Ctrl+B**
- Format Cells dialog: **Ctrl+1**

---

## 4. Formulas and Functions
### 4.1 Arithmetic Operations
**Key Concepts:** Prefix formulas with **=**.

**Example:** `=A1+B1`

### 4.2 Common Functions
- SUM: `=SUM(A1:A10)`
- AVERAGE: `=AVERAGE(B1:B10)`
- MAX/MIN: `=MAX(C1:C10)`, `=MIN(C1:C10)`

**Flowchart for Inserting Functions:**
1. Select cell → **Insert → Function (Fx)**
2. Choose category → Select function → **OK**

**Shortcut Keys:**
- Autosum: **Alt+=**

---

## 5. Cell Referencing
**Key Concepts:**
- Relative: `A1` → adjusts when copied.
- Absolute: `$A$1` → lock row and column.
- Mixed: `$A1` or `A$1`.

**Practical Example:**
Copy `=A1*B1` across columns, then use `$A$1` when referencing a fixed rate.

---

## 6. Creating Charts
**Key Concepts:** Visualize data using bar, line, and pie charts.

**Flowchart:**
1. Select data range
2. **Insert → Chart**
3. Choose chart type → **Next** → Customize → **Finish**

**Common Mistake:**
Selecting blank rows causes misaligned series.

**Shortcut Key:**
- Chart wizard: **F11**

---

## 7. Conditional Formatting
**Key Concepts:** Highlight cells based on criteria.

**Steps:**
1. Select range → **Format → Conditional Formatting**
2. Define condition (e.g., cell value >100)
3. Set style → **OK**

**Shortcut Key:**
- Conditional Formatting: **Ctrl+M**

---

## 8. Data Sorting and Filtering
**Key Concepts:**
- Sort: Ascending/Descending
- Filter: Display rows meeting criteria.

**Steps:**
1. **Data → Sort**
2. Choose key
3. **OK**

**Steps for Filter:**
1. **Data → Filter → Standard Filter**
2. Set field, condition, value → **OK**

**Common Mistake:**
Forgetting to select entire table leads to misaligned rows.

---

## 9. Practical Examples
1. **Sales Report:** Use formulas to compute totals and averages.
2. **Expense Tracker:** Conditional formatting for expenses above budget.
3. **Student Grades:** Generate bar charts of marks.
