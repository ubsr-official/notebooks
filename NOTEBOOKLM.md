## 💡 Tips for Effective Learning

| Tip                                 | Description                                                                                         |
| ----------------------------------- | --------------------------------------------------------------------------------------------------- |
| **🎯 Ask Specific Questions** | Instead of "Explain photosynthesis," try "What are the light and dark reactions in photosynthesis?" |
| **🔗 Connect Concepts**       | Ask how topics relate to each other (e.g., "How does democracy relate to federalism?")              |
| **📝 Request Examples**       | Ask for real-world examples to understand abstract concepts                                         |
| **🧪 Practice Problems**      | Request step-by-step solutions for math and science problems                                        |
| **📊 Compare & Contrast**     | Ask for comparisons (e.g., "Compare mitosis and meiosis")                                           |
