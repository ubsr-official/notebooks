## 1. Introduction

In professional document creation, manual formatting can lead to inconsistencies and inefficiencies, especially in longer documents. Digital documentation using advanced features of LibreOffice Writer enables users to create visually appealing, consistent, and professional documents with minimal effort and maximum impact.

Modern digital documentation requires understanding of automated formatting systems that ensure consistency throughout large documents. These systems reduce time investment while improving document quality and professional appearance.

**Key Benefits of Advanced Digital Documentation:**
- Consistent formatting throughout the document
- Time-efficient document creation and modification
- Professional presentation standards
- Easy maintenance and updates
- Enhanced readability and comprehension

**Shortcut Keys:**
- **Ctrl+N**: Create new document
- **Ctrl+O**: Open existing document
- **Ctrl+S**: Save document

**Footnote 1**: Professional documents often require specific formatting standards that manual formatting cannot efficiently maintain across large documents.

## 3. Styles in Writer

Styles are collections of formatting attributes that can be applied to text, paragraphs, pages, frames, and lists. They ensure consistency and enable rapid formatting changes across entire documents.

### 3.1 Why Styles are Important

**Benefits of Using Styles:**

1. **Consistency**: Ensures uniform formatting throughout the document
2. **Efficiency**: Apply complex formatting with a single click
3. **Maintenance**: Update formatting globally by modifying the style
4. **Professional Appearance**: Creates polished, well-structured documents
5. **Time-Saving**: Eliminates repetitive manual formatting tasks

**Professional Use Cases:**
- Corporate reports with consistent heading structures
- Academic papers requiring specific formatting standards
- Legal documents with standardized paragraph styles
- Technical manuals with uniform formatting requirements

**Shortcut Keys:**
- **Ctrl+1**: Apply Heading 1 style
- **Ctrl+2**: Apply Heading 2 style
- **Ctrl+3**: Apply Heading 3 style
- **Ctrl+0**: Apply Body Text style

**Footnote 3**: Manual formatting changes can be overridden by style applications, which is why understanding style hierarchy is crucial for document management.

### 3.2 Difference between Templates and Styles

**Styles vs Templates Comparison:**

| Aspect | Styles | Templates |
|--------|--------|-----------|
| **Purpose** | Format specific elements within a document | Provide complete document structure and formatting |
| **Scope** | Individual formatting attributes | Entire document layout and content |
| **Application** | Applied to selected text or elements | Used as basis for new documents |
| **Modification** | Changes affect current document | Changes affect new documents created from template |
| **Storage** | Stored within document or template | Stored as separate .ott files |

**Styles**: Formatting instructions for specific document elements
**Templates**: Complete document frameworks including styles, layout, and content structure

**Footnote 4**: A template contains styles, but styles can exist independently within any document.

### 3.3 Types of Styles

LibreOffice Writer provides six categories of styles:

**1. Paragraph Styles**
- Control paragraph formatting (alignment, spacing, indentation)
- Include character formatting attributes
- Examples: Heading 1, Body Text, Quote

**2. Character Styles**
- Format individual characters or words within paragraphs
- Override paragraph style character formatting
- Examples: Bold, Italic, Hyperlink

**3. Page Styles**
- Define page layout (margins, headers, footers, page size)
- Control page orientation and background
- Examples: Default, First Page, Left Page, Right Page

**4. Frame Styles**
- Format text boxes and image frames
- Control borders, backgrounds, and positioning
- Examples: Graphics, Formula, Marginalia

**5. List Styles**
- Format numbered and bulleted lists
- Define list hierarchy and numbering schemes
- Examples: Numbering 1, Bullet 1

**6. Table Styles**
- Format entire tables with consistent appearance
- Control borders, backgrounds, and text formatting
- Examples: Table Header, Academic

**Shortcut Keys:**
- **Ctrl+Shift+F11**: Update selected style
- **Shift+F11**: Create new style from selection

**Footnote 5**: Understanding style categories helps in applying appropriate formatting to different document elements efficiently.

## 4. Applying Styles

Multiple methods exist for applying styles to document elements, each suited to different workflow preferences and efficiency requirements.

**Methods to Apply Styles:**

### Method 1: Styles Deck (Sidebar)
**Steps:**
1. Position cursor in target paragraph or select text
2. Open Styles deck (F11)
3. Double-click desired style name

### Method 2: Styles Menu
**Steps:**
1. Select text or position cursor
2. Click Styles menu on Menu bar
3. Choose appropriate style from list

### Method 3: Formatting Toolbar
**Steps:**
1. Select target text or paragraph
2. Use style dropdown on Formatting toolbar
3. Click desired style

### Method 4: Keyboard Shortcuts
**Steps:**
1. Position cursor appropriately
2. Press keyboard shortcut for desired style
3. Style applies immediately

### Method 5: Fill Format Mode
**Steps:**
1. Open Styles deck (F11)
2. Click Fill Format Mode icon
3. Click on target paragraphs to apply style
4. Press Esc to exit Fill Format Mode

**Shortcut Keys:**
- **Ctrl+M**: Clear direct formatting before applying styles
- **F11**: Toggle Styles window
- **Ctrl+F11**: Set focus to Apply Style box

**Footnote 6**: Fill Format Mode is particularly useful when applying the same style to multiple non-consecutive paragraphs in a document.

## 5. How to Create a New Style

Creating custom styles allows document creators to maintain specific formatting requirements and organizational standards.

### 5.1 Using Drag and Drop to Create New Styles

**Steps:**
1. Format text with desired attributes manually
2. Select the formatted text
3. Open Styles deck (F11)
4. Drag selected text to Styles deck
5. Drop text into appropriate style category
6. Enter style name in dialog box
7. Click OK to create style

**Alternative Method:**
1. Format paragraph with required attributes
2. Open Styles deck (F11)
3. Right-click in Styles deck
4. Select "New Style from Selection"
5. Name the new style
6. Click OK

**Shortcut Keys:**
- **Shift+F11**: Create style from selection

**Footnote 7**: Drag and drop method automatically captures all formatting attributes of the selected text, including character and paragraph formatting.

### 5.2 Updating Existing Styles

**Method 1: Update from Selection**
1. Apply desired formatting to text
2. Select formatted text
3. Open Styles deck (F11)
4. Right-click target style in deck
5. Choose "Update Style from Selection"

**Method 2: Modify Style Dialog**
1. Open Styles deck (F11)
2. Right-click target style
3. Select "Modify" from context menu
4. Adjust settings in Style dialog
5. Click OK to apply changes

**Global Update Effect:**
- All text using the modified style updates automatically
- Changes propagate throughout entire document
- Maintains consistency across all instances

**Shortcut Keys:**
- **Ctrl+Shift+F11**: Update selected style from current formatting

**Footnote 8**: Style updates are one of the most powerful features for maintaining document consistency, as changes apply globally and immediately.

### 5.3 Loading or Copying Styles from a Template

**Steps to Load Styles:**
1. Open document requiring new styles
2. Go to Format menu → Styles → Load Styles
3. Browse and select source template or document
4. Choose style categories to import
5. Select overwrite options if needed
6. Click OK to import styles

**Alternative Method:**
1. Open Styles deck (F11)
2. Click dropdown arrow at top of Styles deck
3. Select "Load Styles from Template"
4. Choose source template
5. Select desired style categories
6. Click OK

**Import Options:**
- **Overwrite existing styles**: Replace conflicting style definitions
- **Don't overwrite**: Keep existing styles, add only new ones
- **Category selection**: Choose specific style types to import

**Footnote 9**: Loading styles from templates enables consistency across multiple documents and standardizes formatting within organizations.

## 6. Inserting and Using Images

Digital documents benefit significantly from visual elements. LibreOffice Writer provides comprehensive image handling capabilities, including **insertion, positioning, resizing, formatting, linking, grouping, and using the Gallery**.

### 6.1 Image Insertion Methods

- **Insert Menu:** Insert → Image → From File
- **Toolbar:** Insert Image icon on Standard toolbar
- **Drag and Drop:** Drag image files directly into document
- **Copy/Paste:** Copy from other applications and paste
- **Insert as Linked:** In Insert Image dialog, check “Link” for a file reference instead of embedding (also works with Ctrl+Shift drag or from Gallery with Ctrl+Shift)

**To break a link and embed a linked image:**  
Edit → External Links (or Edit > Links to External Files) → Select image → Break Link

**Best Practices:** Keep linked images organized with your document for portability. Use embedded images for easy sharing.

### 6.2 Positioning, Anchoring, and Wrapping

Proper positioning affects layout and readability. Use these methods and options:

- **Anchoring Types:**
    - To Page: Image fixed relative to page (for headers, watermarks)
    - To Paragraph: Image moves with paragraph (for illustrations)
    - To Character / As Character: Inline with text (icons, small images)

**Steps to anchor:**  
Right-click image → Properties → (Type tab) Anchor option

- **Text Wrapping Options:**
    - None – no text beside image
    - Before / After – text only on one side
    - Parallel / Optimal / Through – text flows around image or overlays image

**To set wrapping:**  
Right-click image → Wrap submenu or use the Drawing Object Properties toolbar

### 6.3 Modifying Images

#### 6.3.1 Resizing Images

- **Manual Resize:** Drag corner handles for proportional; use Shift for non-proportional (Writer 4.3+ defaults to proportional).
- **Property Dialog:** Right-click → Properties → "Position and Size" to set width/height numerically; check "Keep ratio" for proportional resizing.
- **F4 Panel:** Press F4 for quick size fields.

**Shortcuts:**
- F4: Position/size panel
- Ctrl+D: Duplicate
- Delete: Remove

**Tip:** Always resize with corner handles to avoid distortion.

#### 6.3.2 Grouping and Ungrouping

- **To Group:** Ctrl+Click multiple objects (drawing shapes, frames, or images converted to shapes), right-click → Group
- **To Ungroup:** Select group, right-click → Ungroup
- **Edit within Group:** Double-click to “enter” group, double-click outside to exit
- **Limitation:** Directly inserted images must be in frames/converted to shapes to fully group with other objects

**Shortcuts:**
- Ctrl+Shift+G: Group
- Ctrl+Shift+Alt+G: Ungroup

#### 6.3.3 Drawing Object Properties Toolbar

**Access:**  
Appears when object is selected, or View → Toolbars → Drawing Object Properties

**Key Features:**  
- **Anchor and Align**: Change anchor type and horizontal/vertical alignment
- **Wrap settings**: Control text flow (all options above)
- **Layer order**: Bring to front/back, move up/down layers
- **Line/Border**: Set border style/width/color
- **Fill/Area**: Set background fill/color/gradient/shadow
- **Advanced**: 3D, rotate, flip, crop, transparency, shadow, object locking

**Shortcuts:**  
- Ctrl+Arrow: Move object layer order

**Note:** Toolbar adapts to object type (image, shape, text box).

### 6.4 Using the LibreOffice Gallery

The Gallery contains hundreds of royalty-free graphics, clipart, diagrams, etc.

- **Access:** Sidebar (Gallery tab), Insert > Media > Gallery, or Ctrl+Alt+3
- **Insert:** Drag-and-drop (embed by default, hold Ctrl+Shift to link), or right-click for “Insert”, “Insert as Link” or “Insert as Copy”
- **Edit:** Ungroup to modify many gallery objects (especially in Draw)
- **Best Practice:** Use for copyright-free, consistent graphics in documents

### 6.5 Best Practices and Footnotes

- Use proportional resizing (corner handles or "Keep ratio") to avoid distortions ([see 6.3.1](#631-resizing-images))
- Grouping is best with Draw shapes and frames; images may need conversion for full support ([see 6.3.2](#632-grouping-and-ungrouping))
- Keep all linked images in a known folder, or embed them for easy sharing
- Gallery objects can be customized further via Draw

**Footnotes:**  
- Proportional scaling is default from Writer 4.3 onward; use Shift for non-proportional resizing.  
- Linked images keep file size small and stay up-to-date, but require file management when sharing.

## 7. Creating and Using Document Templates

Templates provide document frameworks that standardize formatting, layout, and content structure across multiple documents, ensuring organizational consistency and efficiency.

### 7.1 Creating a Template

Templates preserve document structure, styles, formatting, and even content for reuse in new documents.

**Method 1: Save As Template**
1. Create and format document completely
2. Add all required styles, headers, footers
3. Include any standard content (logos, addresses)
4. Go to File → Templates → Save As Template
5. Enter template name
6. Select category (folder) for organization
7. Optionally set as default template
8. Click Save

**Method 2: From Existing Document**
1. Open well-formatted existing document
2. Remove specific content, keep structure
3. Save as template using Method 1 steps
4. Template preserves styles and layout

**Template Components to Include:**
- Custom styles for consistent formatting
- Page setup (margins, orientation, size)
- Headers and footers with standard information
- Corporate branding elements
- Standard paragraph and character styles
- Table formats and list styles

**File Extension**: Templates save with .ott extension

**Shortcut Keys:**
- **Ctrl+Shift+N**: Open Templates dialog
- **Ctrl+S**: Save document (not as template)

**Footnote 13**: Templates should be created after careful planning of all formatting requirements to avoid frequent modifications later.

### 7.2 Setting a Default Template

Default templates automatically apply when creating new documents, eliminating repetitive formatting setup.

**Steps to Set Default Template:**
1. Open Templates dialog (Ctrl+Shift+N)
2. Locate desired template
3. Right-click on template
4. Select "Set as Default Template"
5. Default icon appears on template
6. New documents will use this template automatically

**Alternative Method:**
1. When saving template (File → Templates → Save As Template)
2. Check "Set as default template" checkbox
3. Template becomes default immediately

**Changing Default Template:**
1. Open Templates dialog
2. Right-click different template
3. Select "Set as Default Template"
4. Previous default status transfers to new template

**Resetting to System Default:**
1. Open Templates dialog
2. Right-click current default template
3. Select "Reset Default Template"
4. System returns to blank document default

**Footnote 14**: Setting appropriate default templates significantly improves workflow efficiency for users who regularly create similar document types.

### 7.3 Editing a Template

Templates require periodic updates to maintain relevance and incorporate improved formatting standards.

**Steps to Edit Template:**
1. Open Templates dialog (Ctrl+Shift+N)
2. Locate template to modify
3. Right-click on template
4. Select "Edit" from context menu
5. Template opens for modification
6. Make necessary changes to formatting, content, styles
7. Save changes (Ctrl+S)
8. Template updates affect future documents only

**Alternative Editing Method:**
1. Go to File → Templates → Manage Templates
2. Navigate to template location
3. Right-click desired template
4. Choose "Edit"
5. Modify as needed
6. Save changes

**Template Editing Considerations:**
- Existing documents using template remain unchanged
- Only new documents created from template reflect changes
- Test template with sample content before finalizing
- Consider version control for organizational templates

**Shortcut Keys:**
- **Ctrl+S**: Save template changes
- **F11**: Access styles for modification

**Footnote 15**: Template editing affects only future documents; existing documents maintain their current formatting unless manually updated.

### 7.4 Deleting a Template

Template management includes removing outdated or unused templates to maintain organized template libraries.

**Steps to Delete Template:**
1. Open Templates dialog (Ctrl+Shift+N)
2. Navigate to template location
3. Right-click target template
4. Select "Delete" from context menu
5. Confirm deletion in dialog box
6. Template removes from system

**Alternative Deletion Method:**
1. Go to File → Templates → Manage Templates
2. Browse template categories
3. Right-click unwanted template
4. Choose "Delete"
5. Confirm action

**Deletion Considerations:**
- Deleted templates cannot be easily recovered
- Existing documents using template remain functional
- Template styles may become unavailable for new modifications
- Consider archiving instead of deleting valuable templates

**Safety Practices:**
- Export/backup important templates before deletion
- Verify template is truly obsolete
- Check with team members in collaborative environments
- Consider moving to archive folder instead of deleting

**Footnote 16**: Template deletion is permanent; consider careful evaluation and backup procedures before removing templates from the system.

## 8. Table of Contents (ToC)

Table of Contents provides automated navigation and document organization by extracting headings and creating linked references with page numbers.

### 8.1 Opening and Working with ToC Feature

Table of Contents creates structured document navigation based on heading styles, automatically maintaining page number references and providing hyperlink functionality.

**Prerequisites for ToC Creation:**
1. Document must use heading styles (Heading 1, Heading 2, etc.)
2. Headings should be properly hierarchical
3. Document content should be complete or nearly complete

**Steps to Create Table of Contents:**
1. Position cursor where ToC should appear (usually after title page)
2. Go to Insert menu → Table of Contents and Index → Table of Contents, Index or Bibliography
3. Select "Table of Contents" in Type box
4. Configure options:
   - **Evaluate up to level**: Choose heading levels to include (1-10)
   - **Create from**: Select Outline or Styles
   - **Additional Styles**: Include custom heading styles
5. Click OK to insert ToC

**Alternative Quick Method:**
1. Position cursor at desired location
2. Press Ctrl+Shift+F12 (if available)
3. Choose Table of Contents from list
4. Click Insert

**ToC Appearance:**
- Hierarchical list showing document structure
- Page numbers aligned to right margin
- Hyperlinks to actual headings (in digital documents)
- Automatic dot leaders between title and page number

**Shortcut Keys:**
- **Ctrl+Click**: Follow ToC hyperlink to heading
- **F5**: Open Navigator for document navigation

**Footnote 17**: Table of Contents quality depends entirely on consistent use of proper heading styles throughout the document.

### 8.2 Updating ToC

Documents change during writing and editing processes, requiring ToC updates to maintain accuracy of page numbers and heading text.

**When to Update ToC:**
- After adding or removing headings
- After significant content changes affecting page numbers
- After modifying heading text
- Before finalizing document for distribution

**Methods to Update ToC:**

**Method 1: Right-click Update**
1. Right-click anywhere in Table of Contents
2. Select "Update Index/Table" from context menu
3. ToC refreshes automatically

**Method 2: Tools Menu Update**
1. Go to Tools menu → Update → All Indexes and Tables
2. All ToCs and indexes in document update simultaneously

**Method 3: Navigator Update**
1. Open Navigator (F5)
2. Right-click on heading entries
3. Select update options

**Update Types:**
- **Update All**: Refreshes entire ToC structure and page numbers
- **Update Page Numbers Only**: Maintains structure, updates only page references

**Automatic Update Settings:**
1. Right-click in ToC → Edit Index/Table
2. Check "Protected against manual changes"
3. ToC updates automatically when document changes

**Footnote 18**: Regular ToC updates ensure document navigation accuracy and maintain professional document standards.

### 8.3 Customizing ToC

Table of Contents appearance and functionality can be extensively customized to match document requirements and organizational standards.

**Customization Options:**

**1. Level Configuration**
- Choose which heading levels to include (1-10)
- Set different formatting for each level
- Include or exclude specific style types

**2. Formatting Customization**
1. Right-click in ToC → Edit Index/Table
2. **Entries Tab**: Configure each level's appearance
   - Structure: Modify entry components (page numbers, tab stops, hyperlinks)
   - Character styles: Apply specific formatting to each element
   - Tab stops: Adjust spacing and alignment
3. **Styles Tab**: Apply paragraph styles to ToC levels
4. **Columns Tab**: Create multi-column ToC layout
5. **Background Tab**: Add background colors or images

**3. Advanced Structure Options**
- **Entry Text**: E# (Entry number), E (Entry text), T (Tab stop), # (Page number)
- **Hyperlink Options**: LS (Link start), LE (Link end)
- **Custom Elements**: Additional text, formatting codes

**4. Style Applications**
- Apply existing paragraph styles to ToC levels
- Create custom ToC-specific styles
- Control font, size, alignment, spacing for each level

**Visual Customization Examples:**
- **Corporate Style**: Consistent fonts, colors, spacing
- **Academic Format**: Numbered sections, specific indentation
- **Creative Layout**: Custom symbols, varied formatting

**Protection Settings:**
- **Protected against manual changes**: Prevents direct editing
- **Password protection**: Secures ToC from unauthorized modifications

**Footnote 19**: ToC customization enables alignment with specific document standards and organizational branding requirements.

### 8.4 Character Styles in ToC

Character styles within Table of Contents provide fine-grained control over individual elements like page numbers, entry text, and separators.

**ToC Character Style Elements:**
1. **Entry Text**: The heading text itself
2. **Page Numbers**: Numeric page references
3. **Tab Leaders**: Dots or lines between text and numbers
4. **Hyperlink Formatting**: Link appearance and behavior

**Applying Character Styles to ToC:**
1. Right-click in ToC → Edit Index/Table
2. Select **Entries** tab
3. Choose level to modify
4. Select element in Structure line (E, T, #)
5. Click **Character Style** dropdown
6. Choose or create appropriate style
7. Repeat for other elements and levels
8. Click OK to apply

**Common Character Style Applications:**
- **Bold page numbers**: Emphasize page references
- **Italic entry text**: Stylistic text formatting  
- **Colored hyperlinks**: Visual link indication
- **Different fonts**: Distinguish ToC from body text

**Creating Custom ToC Character Styles:**
1. Open Styles deck (F11)
2. Switch to Character Styles tab
3. Right-click → New Style
4. Configure formatting (font, color, effects)
5. Name style appropriately (e.g., "ToC Page Numbers")
6. Apply to ToC elements as described above

**Style Inheritance:**
- ToC character styles can inherit from document character styles
- Changes to base styles automatically update ToC appearance
- Maintains consistency between ToC and document formatting

**Footnote 20**: Character styles in ToC enable precise control over visual hierarchy and document navigation aesthetics.

### 8.5 Deleting ToC

Table of Contents removal requires specific procedures to ensure clean document formatting and avoid formatting disruption.

**Methods to Delete ToC:**

**Method 1: Select and Delete**
1. Click at beginning of ToC
2. Drag to select entire ToC content
3. Press Delete key
4. ToC removes completely

**Method 2: Context Menu Deletion**
1. Right-click anywhere in ToC
2. Select "Delete Index/Table" from menu
3. Confirm deletion if prompted
4. ToC disappears from document

**Method 3: Edit Index Dialog**
1. Right-click in ToC → Edit Index/Table
2. Click **Delete** button in dialog
3. Confirm removal
4. Close dialog

**Post-Deletion Considerations:**
- Page formatting may adjust after ToC removal
- Page numbering sequence continues unaffected
- Heading styles remain intact in document
- Navigation functionality reverts to manual scrolling

**Alternative to Deletion:**
- **Hide ToC**: Make invisible without removing
- **Move ToC**: Cut and paste to different location
- **Replace ToC**: Delete and create new with different settings

**Recovery Options:**
- **Undo (Ctrl+Z)**: Immediate recovery after accidental deletion
- **Recreate**: Use Insert menu to rebuild ToC
- **Document versions**: Restore from previously saved version

**Footnote 21**: ToC deletion only removes the generated table; heading styles and document structure remain completely intact.
