## 🚀 Getting Started

### 🌟 For Students (Beginners)

1. **Choose Your Subject** : Navigate to `/AI-NOTES/{SUBJECT}/`
2. **Read the Notes** : Start with `NOTES.md`
3. **Solve Competency Questions** : Check `/CBSE-SOURCES/CFPQs/`
4. **Take a Mock Test** : Pick a paper from `/PB-PAPERS/` and time yourself!

### 💻 For Contributors

1. **Understand the Structure** : Study `files.json` and this README
2. **Add Your School's Papers** : Have a Pre-Board paper? Scan it (PDF) and submit it!
3. **Use AI Responsibly** : Generate, then verify and improve content
4. **Submit Quality Work** : Focus on accuracy and NCERT alignment
